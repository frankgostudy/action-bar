# 快捷列

貼在螢幕上的快捷鍵列。按一下按鈕，就把該組按鍵送到目前的前景視窗。只要 Windows 和 Python 3，不需要另外安裝套件。

改 `action_bar.pyw` 之前先看「程式架構」和「常用鍵名稱」。用法從「啟動」開始。

## 程式架構

程式本體是 `action_bar.pyw`，只用標準庫：tkinter 畫視窗，ctypes 呼叫 Win32。`啟動.bat` 負責找 `pythonw`。

`enable_dpi()` 必須寫在 `import tkinter` 之前，否則按鈕尺寸會跟著系統縮放跑掉。進入點是 `main()`。互斥名 `Local\TopActionBar.SingleInstance`，同一時間只能有一份；視窗標題是 `TopActionBar`。

### 資料

`config.json` 放位置、透明度、顯示熱鍵、連點開關。`shortcuts.json` 放群組庫，形狀是 `{ "active", "profiles": [ { "name", "enabled", "names" } ] }`。作用中的群組由 `materialize()` 攤成 `self.shortcuts`。這兩個檔和 `error.log` 都是這台電腦的狀態，不要提交。

清單來自 `CATALOG`。`catalog_for("一般")` 傳回全部；`catalog_for("瀏覽器")` 拿掉「擷圖」，讓 `Ctrl+F5` 叫做「強制重新整理」。其他自訂群組不列出瀏覽器專用列。`shortcuts_for()` 遇到第二個 `Ctrl+F5` 會跳過，所以「一般」裡這個組合維持「擷圖」。

常用鍵不在勾選清單裡。`_build_nav_pad()` 固定畫在快捷列最上方：第一列 PgUp、PgDn、Home、End、上、下，第二列 Bksp、Del、Tab、Enter、左、右。

### 視窗與計時

`ActionBar` 管視窗。tkinter 的 `winfo_id()` 常常是子視窗，樣式和視窗程序要加在 `GetAncestor(..., GA_ROOT)` 上。快捷列帶 `WS_EX_NOACTIVATE`，按按鈕不會把前景視窗的焦點搶走。有對話框時才暫時允許啟動。

透明度設在快捷列自己。名稱視窗是另一個 `Toplevel`，alpha 固定 1.0，否則會跟著 0.72 一起變淡。

兩條固定計時：

- `_pump` 每 200ms：把掛起的連點送出去、切換顯示、看前景視窗、以及設定檔和群組檔的修改時間。`_watch_foreground` 只記住前景視窗，不碰名稱。
- `_reinforce` 每 1500ms：把快捷列拉回最前面，接著 `_raise_tip()` 把名稱也拉到它前面。

`relayout()` 一開始就 `_hide_tip()`，然後拆掉按鈕重建。鍵被銷毀時，名稱視窗沒有留下的理由。

### 送出按鍵

`send_hotkey()` 用 `SendInput`。低階滑鼠勾子 `WH_MOUSE_LL` 的回呼裡只能做記號、`PostMessage` 或 `SetTimer`，不能在裡面呼叫 `SendInput`。右鍵補送的事件帶 `dwExtraInfo` 標記 `RIGHT_MARK`，勾子看到這個標記或注入旗標就放行，避免自己觸發自己。

左鍵連點送 `Ctrl+V`，原本的兩下點擊仍會發生。右鍵先攔下來：系統連點時間內的第二下改複製，沒有第二下才在原來的座標補上那次右鍵。

以系統管理員執行的視窗，一般權限的程序送不進按鍵，勾子也到不了那裡。

## 常用鍵名稱

滑鼠停在常用鍵上時，鍵的旁邊出現黑底白字的名稱，例如 `PGUP`、`LEFT`。黑底白字只屬於這個名稱。鍵本身維持淺色；停在上面的那一顆變成藍底白字，滑鼠離開就恢復。

名稱可以蓋住快捷列的其他部分，但要避開游標和目前這一顆鍵。不要把它放到整條快捷列的外面。不要在每 120ms 的監看裡改 `geometry()`，那樣黑底會消失、白字還在。名稱視窗不要加 `WS_EX_TRANSPARENT`。

外框和裡面的字都會收到進入、離開。滑鼠還在同一顆鍵裡時，離開事件直接返回，不當成離開這顆鍵。

### 計時

| 情況 | 時間 | 誰負責 |
| --- | --- | --- |
| 還沒有名稱，第一次停上鍵 | 180ms | `_schedule_tip` |
| 已經有名稱，換到另一顆鍵 | 20ms | `_schedule_tip` |
| 滑出鍵，到空白處 | 80ms | `_schedule_tip_hide` → `_finish_tip_hide` |
| 確認滑鼠是否還在鍵上 | 120ms | `_tip_watch` |

`_schedule_tip` 一進就取消隱藏計時。這顆鍵的名稱已經在畫面上，或這顆鍵的顯示計時已經在排，就返回，不要取消再重排。字的邊緣來回跨過時，180ms 才不會一直往後延。

`_schedule_tip_hide` 一進就取消顯示計時。所以顯示計時和隱藏計時不會同時掛著。`_finish_tip_hide` 維持呼叫 `_hide_tip()`。

`_show_tip` 一開始先清掉顯示計時。滑鼠已經不在那顆鍵上就返回；舊視窗沒有計時可靠，下一次監看會把它關掉。同一顆鍵而且視窗還在，只繼續監看。換鍵時沿用同一個視窗：先改文字，再 `update_idletasks()`，才讀寬高，用 `_tip_origin()` 算位置，`geometry` 同時設大小和位置，最後 `_raise_tip()`。先算位置再改字，字寬不同會讓名稱歪掉。`configure` 或 `geometry` 拋出錯誤，或視窗已經不在，就關掉舊的、新建一個。新建時把字存進 `_tip_label`；`_close_tip_window()` 要把 `_tip_label` 清成 `None`。

`_tip_watch` 看到的鍵是 `None`，或鍵已經被銷毀，直接 `_hide_tip()`。不要因為還有計時就把視窗留著；`relayout()` 重建按鈕時就是這個情況。滑鼠離開且鍵還在時，先把鍵塗回平常色。若顯示計時或 80ms 隱藏計時還在，視窗留著並繼續監看。兩個都沒有，才 `_hide_tip()`。

`_hide_tip()` 會取消顯示、隱藏、監看三種計時，再關掉視窗。`_close_tip_window()` 只關視窗，不取消計時；用來換視窗，不用來處理滑鼠離開。

### 為什麼監看不能順便取消顯示

以前滑鼠從已有名稱的 A 滑到 B，B 排了 180ms 後顯示，但監看每 120ms 看到滑鼠已離開 A，就呼叫 `_hide_tip()`，把 B 的顯示計時一起取消。所以只要名稱已經出現，直接滑到隔壁鍵就一定不會再出現。只有在兩鍵之間停超過 80ms，或之後又在外框和字之間跨一次，才會補出來。

兩鍵之間還有一段更短的空檔：離開 A 時顯示計時已被清掉，進入 B 尚未排上。監看若在這幾毫秒到期，也不能關掉視窗，否則 B 會以為沒有現成的名稱、退回等 180ms。所以「已有隱藏計時」也要先留著視窗。快滑時進入 B 會取消那個隱藏計時，20ms 後改字；滑到空白處則仍約 80ms 後由 `_finish_tip_hide` 關掉。

在有名稱的鍵上按一下、滑鼠不離開，提示留著。`_press_key` 只對沒有名稱的鍵呼叫 `_hide_tip()`。

快速掃過一整排時，名稱會跟著每一顆鍵更新。若覺得太閃，只把 `_schedule_tip` 裡已有名稱時的 20ms 調成 40～60ms，其他不要動。

## 啟動

雙擊 `啟動.bat`。程式會找 `pythonw`，找不到再試 `pyw -3`。

同一時間只能開一份。再啟動一次會出現「快捷列已經在執行。」然後結束。

## 列上的按鈕

| 按鈕 | 作用 |
| --- | --- |
| 拖 | 按住拖到任意位置 |
| 選 | 勾選要出現哪些快捷鍵 |
| 群組名稱 | 切換目前的群組，例如「一般」、「瀏覽器」 |
| 上 | 貼回滑鼠所在螢幕的上緣，並改成橫排 |
| 鼠 | 改到游標右邊、直排。右邊放不下就改到左邊 |
| ⚙ | 開關左鍵連點貼上、右鍵連點複製 |
| — | 縮到通知區域，不進工作列 |
| × | 結束程式 |

在快捷列上按右鍵，會出現同一組功能，也可以在這裡改「顯示／隱藏」熱鍵。在某個快捷鍵按鈕上按右鍵，可選「不要顯示這個」。

按下快捷鍵時，快捷列不會把焦點搶走，也不會因此自動隱藏。

## 顯示與隱藏

預設熱鍵是 `Ctrl+Alt+Shift+H`。再按一次就叫回來。右鍵選單的「設定這個熱鍵」可以改掉；若顯示「未登記」，表示這個組合被別的程式占用。

按「—」之後，快捷列收到通知區域：

- 左鍵：正在顯示就收起，已經收起就叫回來
- 右鍵：顯示、縮到小圖示，或結束

從通知區域收起再結束，下次啟動仍會顯示快捷列。

## 選擇快捷鍵

按「選」打開清單。勾選或取消會立刻出現在列上，不用再按儲存。上方可以打字篩選。

- 「全部」列出這個群組的快捷鍵，「已勾選」只列出有打勾的。
- 右上角是「已勾選數 / 總數」。
- 「全部顯示」「全部隱藏」只切換內建的那些列，不會改到後面自己命名的組合。
- 「儲存」「載入」存的是整份群組庫，包含每個群組的勾選和自訂名稱。

「一般」列出全部快捷鍵。「瀏覽器」用同一套組合，但 `Ctrl+F5` 在「一般」叫「擷圖」，在「瀏覽器」叫「強制重新整理」。瀏覽器裡有沒有勾選，不影響「一般」的清單。

「新增」會用「一般」目前的勾選和名稱做一份新群組。「一般」和「瀏覽器」不能刪。內建項目的名稱不能改；清單後面那些尚未內建的組合可以改名字，改完立刻套用。

快捷鍵寫法用加號，例如 `ctrl+c`、`win+shift+s`。只有減號、沒有加號時也可以寫 `ctrl-c`。加號鍵請寫 `plus`。

## 連點

⚙ 裡有兩個開關，預設都開，而且會記住。

- **左鍵連點**：送出 `Ctrl+V`。不限於輸入框。原本的連點選字動作仍會發生。
- **右鍵連點**：先按住右鍵。在系統連點時間內、而且兩下靠得夠近，就視為連點，不開選單，改送 `Ctrl+C`，複製已經選好的文字。沒有第二下，才在原來的位置補上那次右鍵，選單因此會慢大約一次系統連點的時間。按住後若滑鼠移動超過連點範圍，就當成拖曳，立刻放行。第三下不會再複製一次。

終端機裡若沒有選取文字，`Ctrl+C` 可能是中斷程式。剪貼簿若是檔案或圖片，左鍵連點的 `Ctrl+V` 也可能真的貼出去。

## 檔案

跟 `action_bar.pyw` 放在一起：

- `config.json`：位置、透明度、顯示熱鍵、連點開關
- `shortcuts.json`：群組、勾選、自訂名稱
- `error.log`：執行時的錯誤

這三個是這台電腦上的使用狀態，不放進版本庫。透明度存在設定裡，預設 0.72。

## 限制

- 只在 Windows 上執行。
- 以系統管理員身分執行的視窗，一般權限的快捷列送不進按鍵，右鍵攔截也到不了那裡。需要作用在這類視窗時，請用相同的系統管理員身分啟動快捷列。
- 全螢幕獨占的程式不一定吃得到模擬按鍵。
