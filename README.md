# 快捷列

貼在螢幕上的快捷鍵列。按一下按鈕，就把該組按鍵送到目前的前景視窗。只要 Windows 和 Python 3，不需要另外安裝套件。

改 `action_bar.pyw` 之前先看「程式架構」和「常用鍵名稱」。用法從「啟動」開始。

## 這次更新

勾「顯示」會先確認這個群組還沒有同一組快捷鍵。清單只改那一列，快捷列等設定頁關掉才更新。

- 「顯示」這一欄寫的是目前列上的群組。上方篩選只影響清單，不改這一欄。
- 按鍵擷取綁在設定頁視窗上。名稱欄和搜尋欄在擷取時不會吃掉按鍵。焦點離開視窗就停止。
- 快捷鍵檔唯讀時，換群組、拖進格子、清空格子、從這個群組移除，會提示一次原因。
- 手改 JSON 裡不是物件的群組或快捷鍵會留著，下次存檔原樣寫回。新增後清單會捲到新的那一列。

讀檔時不再把已有的快捷鍵清掉。設定清單用「顯示」決定這一筆要不要出現在目前的群組。

- 沒有版號、但已經有群組和快捷鍵，仍當第 2 版，不會整份重轉。版號比程式新，就唯讀且不改檔案。
- 修補時留下不認得的欄位。讀不起來的原始記錄下次存檔會原樣寫回，切換群組不會把它們刪掉。
- 重複的群組編號先到先得。重複的快捷鍵編號先保留明確的那筆，其餘再另編。
- 設定頁清單可以捲動。新增後群組勾選還在。

快捷鍵改成一筆一筆記錄，不再把每種修飾鍵組合都展開成勾選項。「選」打開的是這份清單，可以新增、修改、刪除，也可以把同一筆放進多個群組。

- 舊的 `shortcuts.json` 在第一次啟動時轉成第 2 版，並另存最早的一份 `shortcuts.v1.bak.json`。轉換後列上先停在「常用」，內容和順序沿用舊的「一般」有勾選的那些。
- 六格改成整份清單共用，記的是快捷鍵編號。換群組不會換掉格子。
- 快捷鍵按鈕的右鍵是「從這個群組移除」。還有別的群組就留著；一個都不剩就變成未分組，不會刪掉，格子裡的也留著。
- 內建清單 `CATALOG` 只在第一次建立、以及這次從舊檔轉換時使用。以後若程式再加新的內建鍵，不會自動補進已經有檔案的使用者。

## 程式架構

程式本體是 `action_bar.pyw`，只用標準庫：tkinter 畫視窗，ctypes 呼叫 Win32。`啟動.bat` 負責找 `pythonw`。

`enable_dpi()` 必須寫在 `import tkinter` 之前，否則按鈕尺寸會跟著系統縮放跑掉。進入點是 `main()`。互斥名 `Local\TopActionBar.SingleInstance`，同一時間只能有一份；視窗標題是 `TopActionBar`。

### 資料

`config.json` 放位置、透明度、顯示熱鍵、連點開關。`shortcuts.json` 是第 2 版：`version`、`next_group_id`、`next_shortcut_id`、`active_group`、`groups`、`shortcuts`、`pins`。群組是 `{ "id", "name" }`，編號只增不重用。快捷鍵是 `{ "id", "hotkey", "name", "groups" }`，`groups` 是群組編號陣列，同一筆可以屬於多個群組。`pins` 是六個快捷鍵編號，空格是 `0`，六格整份清單共用，不跟著群組換。作用中的群組由 `materialize()` 攤成 `self.shortcuts`。這兩個檔、`error.log`、`shortcuts.v1.bak.json` 都是這台電腦的狀態，不要提交。

讀檔時若正規化和檔案不同，只改記憶體，不因為手改一個字就重寫檔案。沒有 `version`、但已經有 `groups` 和 `shortcuts`，仍當第 2 版，不會整份重轉。`version` 大於 2 則這次唯讀，不改檔案。寫檔只發生在轉換成功，以及使用者新增、修改、刪除、換群組、放格子的時候。轉換失敗則這次所有存檔都跳過，記 `error.log`，並提示一次；備份檔已經存在就保留最早那份。檔案讀失敗時保留畫面上的資料，等檔案再改過才重試，唯讀也會跟著恢復。

壞掉的第 2 版會在記憶體裡重整：重複編號先保留明確且不重複的，再把重複的編成最大編號加一；群組編號先到先得。不存在的群組編號拿掉、格子裡不存在的編號變 0、計數器至少是最大編號加一。無效組合略過並寫進 `error.log`，原始那一筆留著，下次存檔原樣寫回。不是物件的群組或快捷鍵也原樣留著。不認得的欄位留在原記錄上。

`CATALOG` 只用來建立新檔，以及把舊版轉過來。沒有事後同步。`catalog_for()`、`shortcuts_for()` 留著給轉換對照：舊「瀏覽器」的 `Ctrl+F5` 轉成「強制重新整理」，其他群組的 `Ctrl+F5` 轉成「擷圖」。目錄裡沒有的組合，包括格子裡還留著、但已經取消勾選的，轉成「自訂」的新記錄。群組名稱可以改、可以刪；程式不要寫死「常用」。作用中的群組不見了就改用陣列第一個，全部刪光就再建一個空的「常用」。種子編號 1～8 只在建立和轉換時使用。全新安裝沒有檔案時，啟動停在第一個有成員的群組（「編輯」）。空群組的列上顯示「這個群組還沒有快捷鍵，按『選』加入」。未分組只在設定頁當篩選，不出現在列上的群組選單。

方向鍵、PgUp、Bksp 這些常用鍵不在快捷鍵清單裡，也不占用編號。`_build_nav_pad()` 固定畫在快捷列最上方：第一列 PgUp、PgDn、Home、End、上、下，第二列 Bksp、Del、Tab、Enter、左、右。再往下是分隔線、六個格子、另一條分隔線，跟這六欄對齊。`column_count(..., reserve=136)` 把工具列、常用鍵和這排格子的高度預留出來。

### 視窗與計時

`ActionBar` 管視窗。tkinter 的 `winfo_id()` 常常是子視窗，樣式和視窗程序要加在 `GetAncestor(..., GA_ROOT)` 上。快捷列帶 `WS_EX_NOACTIVATE`，按按鈕不會把前景視窗的焦點搶走。有對話框時才暫時允許啟動。

透明度設在快捷列自己。名稱視窗是另一個 `Toplevel`，alpha 固定 1.0，否則會跟著 0.72 一起變淡。

兩條固定計時：

- `_pump` 每 200ms：把掛起的連點送出去、切換顯示、看前景視窗、以及設定檔和群組檔的修改時間。`_watch_foreground` 只記住前景視窗，不碰名稱。
- `_reinforce` 每 1500ms：把快捷列拉回最前面，接著 `_raise_tip()` 把名稱也拉到它前面。

`relayout()` 一開始就 `_hide_tip()`，然後拆掉按鈕重建。鍵被銷毀時，名稱視窗沒有留下的理由。

### 送出按鍵

`send_hotkey()` 用 `SendInput`。低階滑鼠勾子 `WH_MOUSE_LL` 的回呼裡只能做記號、`PostMessage` 或 `SetTimer`，不能在裡面呼叫 `SendInput`。右鍵補送的事件帶 `dwExtraInfo` 標記 `RIGHT_MARK`，勾子看到這個標記或注入旗標就放行，避免自己觸發自己。

左鍵連點送 `Ctrl+V`，原本的兩下點擊仍會發生。右鍵先攔下來：系統連點時間內的第二下改複製，沒有第二下才在原來的座標補上那次右鍵。

以系統管理員執行的視窗，一般權限的程序送不進按鍵，勾子也到不了那裡。

## 常用鍵名稱

滑鼠停在常用鍵上時，鍵的旁邊出現黑底白字的名稱，例如 `PGUP`、`LEFT`。黑底白字只屬於這個名稱。鍵本身維持淺色；停在上面的那一顆變成藍底白字，滑鼠離開就恢復。

名稱可以蓋住快捷列的其他部分，但要避開游標和目前這一顆鍵。不要把它放到整條快捷列的外面。不要在每 120ms 的監看裡改 `geometry()`，那樣黑底會消失、白字還在。名稱視窗不要加 `WS_EX_TRANSPARENT`。

外框和裡面的字都會收到進入、離開。滑鼠還在同一顆鍵裡時，離開事件直接返回，不當成離開這顆鍵。

### 計時

| 情況 | 時間 | 誰負責 |
| --- | --- | --- |
| 還沒有名稱，第一次停上鍵 | 180ms | `_schedule_tip` |
| 已經有名稱，換到另一顆鍵 | 20ms | `_schedule_tip` |
| 滑出鍵，到空白處 | 80ms | `_schedule_tip_hide` → `_finish_tip_hide` |
| 確認滑鼠是否還在鍵上 | 120ms | `_tip_watch` |

`_schedule_tip` 一進就取消隱藏計時。這顆鍵的名稱已經在畫面上，或這顆鍵的顯示計時已經在排，就返回，不要取消再重排。字的邊緣來回跨過時，180ms 才不會一直往後延。

`_schedule_tip_hide` 一進就取消顯示計時。所以顯示計時和隱藏計時不會同時掛著。`_finish_tip_hide` 維持呼叫 `_hide_tip()`。

`_show_tip` 一開始先清掉顯示計時。滑鼠已經不在那顆鍵上就返回；舊視窗沒有計時可靠，下一次監看會把它關掉。同一顆鍵而且視窗還在，只繼續監看。換鍵時沿用同一個視窗：先改文字，再 `update_idletasks()`，才讀寬高，用 `_tip_origin()` 算位置，`geometry` 同時設大小和位置，最後 `_raise_tip()`。先算位置再改字，字寬不同會讓名稱歪掉。`configure` 或 `geometry` 拋出錯誤，或視窗已經不在，就關掉舊的、新建一個。新建時把字存進 `_tip_label`；`_close_tip_window()` 要把 `_tip_label` 清成 `None`。

`_tip_watch` 看到的鍵是 `None`，或鍵已經被銷毀，直接 `_hide_tip()`。不要因為還有計時就把視窗留著；`relayout()` 重建按鈕時就是這個情況。滑鼠離開且鍵還在時，先把鍵塗回平常色。若顯示計時或 80ms 隱藏計時還在，視窗留著並繼續監看。兩個都沒有，才 `_hide_tip()`。

`_hide_tip()` 會取消顯示、隱藏、監看三種計時，再關掉視窗。`_close_tip_window()` 只關視窗，不取消計時；用來換視窗，不用來處理滑鼠離開。

### 為什麼監看不能順便取消顯示

以前滑鼠從已有名稱的 A 滑到 B，B 排了 180ms 後顯示，但監看每 120ms 看到滑鼠已離開 A，就呼叫 `_hide_tip()`，把 B 的顯示計時一起取消。所以只要名稱已經出現，直接滑到隔壁鍵就一定不會再出現。只有在兩鍵之間停超過 80ms，或之後又在外框和字之間跨一次，才會補出來。

兩鍵之間還有一段更短的空檔：離開 A 時顯示計時已被清掉，進入 B 尚未排上。監看若在這幾毫秒到期，也不能關掉視窗，否則 B 會以為沒有現成的名稱、退回等 180ms。所以「已有隱藏計時」也要先留著視窗。快滑時進入 B 會取消那個隱藏計時，20ms 後改字；滑到空白處則仍約 80ms 後由 `_finish_tip_hide` 關掉。

在有名稱的鍵上按一下、滑鼠不離開，提示留著。`_press_key` 只對沒有名稱的鍵呼叫 `_hide_tip()`。

快速掃過一整排時，名稱會跟著每一顆鍵更新。若覺得太閃，只把 `_schedule_tip` 裡已有名稱時的 20ms 調成 40～60ms，其他不要動。

## 格子

六格在 Bksp 那一列下面，上下各一條橫線。一開始是空的。六格是整份清單共用的，`pins` 存快捷鍵編號。換群組、改名稱、改組合，格子都跟著同一筆編號。刪掉那一筆，格子才清成 0。

從底下清單按住並移動超過 6px 才算拖拉。沒超過就放開，仍送出原本的按鍵。拖過之後不論放在哪，都不送出按鍵。放開時不在格子上，格子維持原樣。落在格子上就取代那一格；同一組合原本在別格會被清掉。取消沒有 Esc，放到格子外面即可。

拖拉中把 `_dragging` 設成真，讓設定和群組重讀暫停。不要呼叫 `_drag_end`，那個會把視窗改成自由拖曳並寫入座標。小視窗是黃底，跟名稱的黑底分開，也不要拿 `_tip` 來當它。拖到格子上時那一格亮黃框，框線厚度不變。

放下後只重建有變動的格子，不呼叫 `relayout()`。字從編號查出那一筆：三字以內照放，更長取前兩字加「…」，沒有名稱就放主鍵。懸停是「名稱 · 快捷鍵」。從群組移除不會清掉已經放進格子的鍵。有內容的格子右鍵第一項是「清空這格」，下面接原本的列選單。

「選」開著時不要開始拖拉，也不要清空格子或從群組移除。這三處都要看 `_editors`。左鍵已經放開但紀錄還在時，`_pump` 會把拖拉清掉，避免 `_dragging` 卡住。設定頁直接改 `self.library`，每次新增、修改、刪除立刻存檔；列等到對話框關閉才重排一次。

## 啟動

雙擊 `啟動.bat`。程式會找 `pythonw`，找不到再試 `pyw -3`。

同一時間只能開一份。再啟動一次會出現「快捷列已經在執行。」然後結束。

## 列上的按鈕

| 按鈕 | 作用 |
| --- | --- |
| 拖 | 按住拖到任意位置 |
| 選 | 打開快捷鍵清單，新增、修改、刪除，或改群組 |
| 群組名稱 | 切換目前的群組。未分組不在這裡 |
| 上 | 貼回滑鼠所在螢幕的上緣，並改成橫排 |
| 鼠 | 改到游標右邊、直排。右邊放不下就改到左邊 |
| ⚙ | 開關左鍵連點貼上、右鍵連點複製 |
| — | 縮到通知區域，不進工作列 |
| × | 結束程式 |

在快捷列上按右鍵，會出現同一組功能，也可以在這裡改「顯示／隱藏」熱鍵。在某個快捷鍵按鈕上按右鍵，可選「從這個群組移除」。常用鍵下方的六格，有內容時右鍵第一項是「清空這格」。

按下快捷鍵時，快捷列不會把焦點搶走，也不會因此自動隱藏。

## 顯示與隱藏

預設熱鍵是 `Ctrl+Alt+Shift+H`。再按一次就叫回來。右鍵選單的「設定這個熱鍵」可以改掉；若顯示「未登記」，表示這個組合被別的程式占用。

按「—」之後，快捷列收到通知區域：

- 左鍵：正在顯示就收起，已經收起就叫回來
- 右鍵：顯示、縮到小圖示，或結束

從通知區域收起再結束，下次啟動仍會顯示快捷列。

## 選擇快捷鍵

按「選」打開清單。上方可以依群組篩選（含「全部」和「未分組」），也可以打字搜尋。清單列出已經存在的快捷鍵，不再展開全部修飾鍵組合。

第一欄「顯示」對的是目前列上的那個群組，欄名會帶上群組名稱。勾了，這一筆才出現在列上；取消就從這個群組拿掉，其他群組的歸屬還在。同一個組合在這個群組已經有了，就勾不上去。清單只改那一列。快捷列要等這個視窗關掉才更新。上方的群組篩選只影響清單，不改變這一欄改的是哪個群組。

表單有 Ctrl、Shift、Alt、Win 四個勾選，主鍵是下拉清單，列出所有可用鍵名。旁邊的「按下主鍵」只是幫你填進這個下拉：按鍵綁在設定頁視窗上，也綁在名稱欄和搜尋欄上，用 `keycode` 對回鍵名。修飾鍵略過。擷取中這些欄回傳 `"break"`，字不會打進去。Esc 會取消擷取；要設成 Esc，改從下拉選。焦點離開這個視窗就停止擷取；在視窗裡換到別的欄不會停。中文輸入法送不出鍵時，預覽會寫「這個鍵無法擷取，請用下拉」。媒體鍵、小鍵盤、F13～F24、PrintScreen 不一定按得到，也從下拉選。

「新增」永遠是新的一筆。「儲存修改」只改選中的那一筆。「刪除」會把用到它的格子清掉。「群組管理」可以新增、改名、刪除群組。刪除群組時，只屬於該群組的快捷鍵變成未分組，不會刪除。

同一筆組合加同一個名稱已經存在時，不要只說不行，要提示到現有那一筆的群組欄勾選。同一個群組裡，同一個組合只能有一筆。名稱可以空著，格子上就顯示主鍵。不同組合可以用相同名稱。

快捷鍵寫法用加號，例如 `ctrl+c`、`win+shift+s`。只有減號、沒有加號時也可以寫 `ctrl-c`。加號鍵請寫 `plus`。反引號是 `backquote`。

## 連點

⚙ 裡有兩個開關，預設都開，而且會記住。

- **左鍵連點**：送出 `Ctrl+V`。不限於輸入框。原本的連點選字動作仍會發生。
- **右鍵連點**：先按住右鍵。在系統連點時間內、而且兩下靠得夠近，就視為連點，不開選單，改送 `Ctrl+C`，複製已經選好的文字。沒有第二下，才在原來的位置補上那次右鍵，選單因此會慢大約一次系統連點的時間。按住後若滑鼠移動超過連點範圍，就當成拖曳，立刻放行。第三下不會再複製一次。

終端機裡若沒有選取文字，`Ctrl+C` 可能是中斷程式。剪貼簿若是檔案或圖片，左鍵連點的 `Ctrl+V` 也可能真的貼出去。

## 檔案

跟 `action_bar.pyw` 放在一起：

- `config.json`：位置、透明度、顯示熱鍵、連點開關
- `shortcuts.json`：群組、快捷鍵、六格編號
- `error.log`：執行時的錯誤

這三個是這台電腦上的使用狀態，不放進版本庫。透明度存在設定裡，預設 0.72。

## 限制

- 只在 Windows 上執行。
- 以系統管理員身分執行的視窗，一般權限的快捷列送不進按鍵，右鍵攔截也到不了那裡。需要作用在這類視窗時，請用相同的系統管理員身分啟動快捷列。
- 全螢幕獨占的程式不一定吃得到模擬按鍵。
